# LLD Interview Preparation

This repository contains Low-Level Design (LLD) interview questions, including Object-Oriented Programming, SOLID principles, Design Patterns, and hands-on LLD problems implemented in Java.

## Prerequisites

Before starting LLD preparation, you should be comfortable with the following:

### 1. Programming Language

* Be well-versed in at least one programming language.
* For this repository, Java is used for implementation.
* Have a good understanding of classes, objects, interfaces, collections, exceptions, and basic Java features.

### 2. Object-Oriented Programming (OOP)

You should be familiar with the core OOP concepts:

* Encapsulation
* Abstraction
* Inheritance
* Polymorphism
* Composition vs. Inheritance
* Association, Aggregation, and Composition
* Interfaces and Abstract Classes

### 3. Design Patterns

You should have a basic understanding of commonly used Design Patterns and their purpose.

The repository covers patterns such as:

* Creational:Singleton, Factory, Abstract Factory, Builder
* Structural: Adapter, Decorator, Facade, Proxy
* Behavioral: Strategy, Observer, Command, Template Method, Chain of Responsibility
